Moto Studio Backup

Moto Studio Backup is a private utility maintained by its Google account owner. It copies the owner's local video-production library to the owner's Google Drive as versioned archives.

How it works

The owner authorizes the app and explicitly selects its backup destination in Google's folder picker. The app requests only Google's drive.file permission, which limits access to files the app creates or the owner explicitly grants it access to.

Backups use dated manifests and checksums. Completion is recorded after verification. Restore tests write into a new local directory. The utility does not publish videos or synchronize cloud changes back into the production workspace.

Owner control

Scheduled backups are enabled only after the owner approves setup and verification. The utility has no automatic deletion or archive-pruning operation. This is a personal workflow utility, not a public backup service.
