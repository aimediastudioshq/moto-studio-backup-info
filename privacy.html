Moto Studio Backup

Privacy policy

Effective October 20, 2026. Moto Studio Backup is a private Windows utility operated by its Google account owner for a personal production workflow.

Information processed

The utility processes files placed in the owner's configured production workspace, relative paths, file sizes, modification times, checksums and backup dates. It reads the authorized Google account email address to verify the intended account, storage quota, and metadata or content of files the app creates or the owner explicitly grants it access to. It requests only the Google Drive drive.file scope.

Use and sharing

Production file copies, recovery manifests and verification requests are sent to the owner's Google Drive for backup and restoration. The utility does not sell this data, use it for advertising, or send it to generative AI services. Google processes uploaded files under the owner's Google account and applicable Google service policies. This utility's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Credential protection

Offline authorization credentials are encrypted with Windows DPAPI in the current user's Local AppData directory. They are not stored in the production library, synced backup folders, website files or logs. Software running with the same Windows user's privileges may still access that user's resources; this protection does not secure a compromised Windows account.

Retention and control

Backups are retained as versions. The utility performs no automatic remote pruning or local cleanup. The owner can revoke the app's access through their Google Account. Revocation does not remove backups already uploaded. Deletion and retention changes require the owner's separate approval.

Website and contact

This static website has no analytics, cookies, forms or sign-in code of its own. Its hosting provider may process ordinary HTTP request information under that provider's policies. For questions about the app, use the support email displayed on Google's consent screen. No production files or credentials are hosted on this website.
